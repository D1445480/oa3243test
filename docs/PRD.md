# 產品需求文件 (PRD)

## 專案名稱
校園活動資訊整合平台

## 1. 專案概述

### 背景與動機
現在很多大學生常因資訊分散，錯過校內重要活動（例如講座、社團招生、競賽、工讀或學校公告）。活動資訊可能散落在學校官網、系所網站、社群平台、LINE 群組或實體海報中，導致學生需要花費大量時間搜尋，也容易因資訊不完整而降低參與意願。為解決資訊傳播零散與曝光不足的問題，我們希望打造一個統一集中的資訊交流環境。

### 目標用戶
- 大學生（一般學生）
- 社團幹部
- 系學會成員
- 校內活動主辦單位（校方或各系所單位）

### 核心價值主張
將各類校園活動集中管理，提供清楚的分類、搜尋與瀏覽功能，讓學生能更快速掌握校園最新資訊，提升活動參與率與資訊取得效率。同時，協助校方、社團或活動主辦單位更有效率地宣傳活動，打造更便利、更即時的校園資訊交流環境。

---

## 2. 功能需求

以下列出本系統的主要功能，並以使用者故事 (User Story) 的方式描述：

### 1. 活動資訊瀏覽 (MVP 核心)
**作為一般學生，我希望能夠查看校園內各類活動資訊（包含活動名稱、時間、地點、內容等），以便快速了解校園近期動態。**

### 2. 活動分類與搜尋 (MVP 核心)
**作為一般學生，我希望能夠透過分類篩選及關鍵字搜尋功能，以便快速查找到符合我興趣或需求的活動。**

### 3. 主辦單位發布活動
**作為活動主辦單位，我希望能夠在平台上新增與發布活動資訊，以便有效地向全校學生宣傳我的活動。**

### 4. 會員註冊與身分管理
**作為平台使用者（學生或主辦方），我希望能夠註冊專屬帳號並登入系統，以便享有後續的進階功能（如收藏、發布活動）。**

### 5. 活動收藏與追蹤
**作為一般學生，我希望能夠將感興趣的活動加入個人收藏清單，以便日後追蹤，避免遺漏重要行程。**

### 6. 最新活動通知
**作為平台訂閱用戶，我希望當有全新活動發布時，能夠即時收到系統發送的簡訊通知，以便第一時間掌握活動動態。**

---

## 3. 非功能需求

### 技術限制
- **後端框架**：使用 Python Flask 框架開發。
- **模板引擎**：前端畫面使用 HTML/CSS 搭配 Jinja2 渲染，不採用前後端分離架構。
- **資料庫**：使用 SQLite 搭配 ORM（如 SQLAlchemy），輕量且適合 MVP 開發與測試。

### 效能與安全考量
- 平台須具備基礎的響應式設計 (RWD)，確保學生使用手機瀏覽時體驗順暢。
- 需要預防基礎的資訊安全風險（例如 SQL Injection），密碼需經過加密（如 bcrypt）儲存。
- 若活動數量增多，列表頁面需加入分頁機制 (Pagination) 以確保網頁載入速度。

---

## 4. MVP 範圍 (Minimum Viable Product)

### Must Have (第一階段必備功能)
- 首頁與活動列表的瀏覽功能。
- 活動詳細資訊的呈現。
- 以關鍵字或分類標籤進行活動搜尋與過濾。
- 基礎的前端介面與版型設計。

### Should Have (第二階段重要功能)
- 會員註冊與登入系統（包含手機號碼輸入與訂閱功能）。
- 主辦單位專屬的活動新增/編輯/刪除管理後台。
- 學生專屬的活動收藏功能。
- **最新活動簡訊通知功能** (發布活動時自動觸發簡訊寄送予訂閱者)。

### Nice to Have (未來擴充功能)
- 線上報名與人數統計機制。
- 活動前提醒通知（Email 或推播）。
- 行事曆視圖模式。
